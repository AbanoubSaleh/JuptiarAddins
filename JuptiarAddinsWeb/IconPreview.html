🔄 How to Apply Changes

  1. Replace the copied icon files with actual professional icons
  2. Restart Word completely to reload the manifest
  3. Reinstall the add-in if needed
  4. Check the Jupiter tab for the new icons

📝 Icon Requirements

  • Sizes: 16x16, 32x32, and 80x80 pixels
  • Format: PNG with transparent background
  • Style: Office Fluent UI compatible
  • Colors: Use Office theme colors (blues, grays)
