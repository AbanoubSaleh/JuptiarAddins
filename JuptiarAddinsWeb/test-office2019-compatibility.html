🏢 Office 2019 Compatibility Test

ℹ️ About Office 2019 Limitations

Office 2019 has limited support for dynamic ribbon updates compared to Office 365/Microsoft 365. The Office.ribbon.requestUpdate API is not available, which means:

  • ✅ Buttons remain visible - All Jupiter buttons will always be visible in the ribbon
  • ✅ Smart button behavior - Buttons check document state when clicked and show appropriate messages
  • ✅ Document detection works - The add-in can still detect document types correctly
  • ✅ State management works - Document state is properly tracked and persisted

⚠️ Expected Behavior in Office 2019

Since dynamic ribbon updates aren't supported:

  • New Document: All buttons visible, but Properties/Check Out/Check In show "not available" messages when clicked
  • Jupiter Document: All buttons visible and functional
  • External Document: All buttons visible, but Properties/Check Out/Check In show "not available" messages when clicked
